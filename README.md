# BasicFrame

A basic Java Swing project created while learning how to build graphical user interfaces (GUIs) in Java.

## About

This project demonstrates the fundamentals of creating a window using Java Swing and the `JFrame` class.

The application creates a simple GUI frame with basic window properties such as:

- Custom window title
- Defined window dimensions
- Resizable window
- Default close operation
- Basic colour configuration

## Technologies

- Java
- Java Swing

## Project Structure

- `BasicFrameApp.java` – Contains the main method and launches the application.
- `MyFirstFrame.java` – Defines the GUI window by extending `JFrame`.

## Note

This is an early learning project created while practicing Java GUI development.
